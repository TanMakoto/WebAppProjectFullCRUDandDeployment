📘 Northwind BMS — RESTful API Documentation

วิชาการพัฒนา Web Application (CPE PSRU) · สถาปัตยกรรม RESTful API ด้วย Pure PHP + PDO OOP + JWT

🖥️ ไปยังระบบหลัก 📄 ดาวน์โหลด Markdown
Base URL: http://your-domain.com/northwind/api/ หรือ http://localhost:8000/api/index.php?endpoint=
Header สำหรับ Endpoint ที่มีการป้องกัน: Authorization: Bearer <jwt_token>

🔐 1. Authentication & Security

POST /api/auth/login — เข้าสู่ระบบและรับ JWT Token
Request Headers:
Content-Type: application/json
Request Body:
{
  "username": "admin@northwind.co.th",
  "password": "admin"
}
Response (200 OK):
{
  "status": true,
  "message": "เข้าสู่ระบบสำเร็จ",
  "data": {
    "token": "eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9...",
    "user": {
      "id": 1,
      "username": "admin",
      "email": "admin@northwind.co.th",
      "full_name": "วชิรา ล.",
      "role": "ผู้ดูแลระบบ",
      "avatar": "วช"
    }
  }
}

📦 2. Products Module

GET /api/products — ดึงรายการสินค้าทั้งหมด พร้อมตัวกรองและแบ่งหน้า
Query Parameters:
  • search (string) - ค้นหาตามชื่อสินค้า
  • category_id (int) - รหัสหมวดหมู่
  • supplier_id (int) - รหัสผู้จัดจำหน่าย
  • status (string) - in_stock, low_stock, out_of_stock, discontinued
  • page (int) - หมายเลขหน้า (เริ่มต้น 1)
  • limit (int) - จำนวนรายการต่อหน้า (เริ่มต้น 20)
Response (200 OK):
{
  "status": true,
  "message": "ดึงรายการสินค้าสำเร็จ",
  "total": 20,
  "page": 1,
  "limit": 20,
  "total_pages": 1,
  "data": [
    {
      "product_id": 1,
      "product_name": "ชาไทย Chai",
      "category_id": 1,
      "category_name": "เครื่องดื่ม",
      "supplier_name": "Exotic Liquids",
      "quantity_per_unit": "10 กล่อง x 20 ซอง",
      "unit_price": 630.00,
      "units_in_stock": 39,
      "discontinued": 0
    }
  ]
}
POST /api/products — เพิ่มสินค้าใหม่
Bearer Auth
Request Body:
{
  "product_name": "กาแฟดอยช้าง Organic",
  "category_id": 1,
  "supplier_id": 1,
  "quantity_per_unit": "ถุงละ 250 กรัม",
  "unit_price": 350.00,
  "units_in_stock": 50,
  "discontinued": 0
}
Response (201 Created):
{
  "status": true,
  "message": "เพิ่มสินค้าเรียบร้อยแล้ว",
  "data": {
    "product_id": 21,
    "product_name": "กาแฟดอยช้าง Organic",
    "unit_price": 350.00
  }
}
PUT /api/products/{id} — แก้ไขข้อมูลสินค้า
Bearer Auth
Response (200 OK):
{
  "status": true,
  "message": "แก้ไขข้อมูลสินค้าเรียบร้อยแล้ว",
  "data": { ... }
}
DELETE /api/products/{id} — ลบสินค้าตาม ID
Bearer Auth
Response (200 OK):
{
  "status": true,
  "message": "ลบสินค้าเรียบร้อยแล้ว"
}

🗂 5. Other CRUD Modules

ทุกโมดูลต่อไปนี้รองรับ HTTP Methods: GET, POST, PUT, DELETE:

  • /api/categories — จัดการหมวดหมู่สินค้า (CRUD)
  • /api/customers — จัดการข้อมูลลูกค้า (CRUD)
  • /api/suppliers — จัดการผู้จัดจำหน่าย (CRUD)
  • /api/employees — จัดการรายชื่อพนักงาน (CRUD)
  • /api/shippers — จัดการบริษัทขนส่ง (CRUD)
  • /api/reports/dashboard — รายงานสถิติและข้อมูลสำหรับ Export
